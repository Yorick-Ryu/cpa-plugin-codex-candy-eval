# v0.4.6-omc.1

Merge upstream v0.4.6 through `86d832c58f85f33e0cff91368fae1cb1012899f8`.

- Add SIWC checks for bound Codex auth files, with shared-credential switches,
  classified errors and separate history in the React/Base UI interface.
- Use the OMCPA session for hosted management requests. Ignore stale CPA keys
  in hosted mode and keep shared-session model catalogs in memory.
- Preserve the independent OMC plugin ID, Ciallo rules and original replies,
  credential ordering, model cooldown handling, OMCPA fonts and natural scrolling.
- Retain the existing inspection API used by account operations; no worker update
  or service restart is required.

Validation: TypeScript, embedded frontend build, React contracts, direct and
hosted component flows, legacy helper contracts, theme bridge, native Chromium
wheel/touch and modal scroll-lock checks, Go vet and race tests. Model requests
and credential setting changes in these checks use only local synthetic data.
Production verification is read-only; no live evaluation or SIWC switch change
is part of this release verification.

State upgrades from schema 2 to 3 and writes an original `.v2.json` backup.
Existing candy/Ciallo, fingerprint and pelican records remain. Before reverting
an old binary, preserve the latest schema-3 state (including SIWC history), then
change the copy used by the old binary to schema 2. Do not overwrite newer
non-SIWC results with the pre-upgrade backup. Deployment receipts and exact
rollback paths belong under the server workspace's dated artifacts directory.
